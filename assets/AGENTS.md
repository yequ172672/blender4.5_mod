# assets

## Purpose
Built-in asset library shipped with Blender, including brush presets and geometry node group presets.

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| brushes/ | Brush preset assets for sculpting, painting, and texture tools |
| geometry_nodes/ | Geometry node group preset assets for procedural modeling and effects |

## For AI Agents
### Working In This Directory
This directory contains asset data files (not source code). Changes here affect the default asset library available to all Blender users. Asset files are typically authored within Blender and exported. When modifying assets, ensure compatibility with the current Blender version and verify that asset metadata (previews, catalogs) remains consistent.
